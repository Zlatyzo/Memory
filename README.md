# Memory Game - JavaScript Assignment

## Project Overview

This project is an interactive web application implementing a classic Memory card game. The objective is to find 8 matching pairs of images hidden across the game board. Images are dynamically fetched from the Picsum Photos API upon starting a new game.

## Key Features

* Dynamic fetching and random shuffling of image pairs for every new session.
* Real-time timer tracking elapsed time in minutes and seconds.
* Move counter tracking the total number of attempts.
* Victory summary message displaying final performance stats upon completion.
* Restart button to re-initialize and shuffle the game board at any time.
* Responsive design adapting to mobile and smaller screen sizes.
